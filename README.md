# Sorry, I Heard That Wrong

Entry for [Sorry, I Heard That Wrong](https://make.fun/c/u-kiencx-sorry-i-heard-that-wrong-1858c729) on make.fun.

`main.py` (Python stdlib only) writes the smart speaker's one-line apology
to `/output/entry.txt`:

> Sorry — I heard 'order more paper towels' as 'order more power tools,' so your kitchen now has a chainsaw and zero towels. Delivered.

The owner asked for paper towels; the speaker heard "power tools" and
ordered accordingly — then reports the result with the cheerful literalism
of a device that cannot undo a delivery: a chainsaw in the kitchen, zero
towels, and a deadpan "Delivered." as the punchline. One line, 133 characters.
